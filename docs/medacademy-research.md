## 2. Слабые места текущего сайта — измерено

Замеры — Playwright + Chromium, эмуляция телефона 390×844 из облака, без
троттлинга сети. На реальном 4G будет медленнее.

| Что | Намерили |
|---|---|
| Вес главной | **9,7 МБ**, 25 запросов (фото по 2048 px на телефон) |
| Скорость главной | первый байт 1,4 с, первая отрисовка 2,9 с, `load` **8,2 с** |
| Шрифт | Sen подключён только с `subset=latin`: заголовки на кириллице падают в Times — на скриншоте видна смесь гарнитур |
| Мобильная вёрстка | «Преподаватели»: `scrollWidth` 398 при ширине экрана 390, страница уезжает вбок |
| Данные | Без JS (так страницу видят превью ссылок и простые краулеры) карточки Самиры, Рашида и Хонзоды показывают текст Азамата |
| Безопасность | `/ru/teachers-list-single-page-layout/` и `/ru/courses-list-single-page-layout/` отдают Apache «Index of» — листинг каталогов открыт |
| Остатки шаблона | «Population mapping» на «Контактах», Legal Notice на английском, «Учителя» и «Преподаватели» вперемешку, стоки Unsplash |
| Языки | Только русский: `/uz/` отдаёт 404 |
| Путь до заявки | Формы нет. Telegram — только иконкой в подвале. Кнопки «Подробнее» и «Связаться» ведут на страницы, а не в чат. На главной нет ни цен, ни имён преподавателей |

## 4. Экзамен — факты для калькулятора

- **DTM (UZBMB).** 90 вопросов, максимум 189:
  - обязательные предметы — 30 вопросов × 1,1 = 33;
  - первый профильный (биология) — 30 × 3,1 = 93;
  - второй профильный (химия) — 30 × 2,1 = 63.
  - Источники:
    [oliygoh.uz](https://oliygoh.uz/post/maksimal-ball-189-boladi-5-ta-fan-90-ta-test-3-soat-vaqt),
    [infoedu.uz](https://infoedu.uz/abituriyentlar-kirish-imtihonida-quyidagi-blok-fanlardan-ball-toplashlari-mumkin),
    [ustabor.uz](https://education.ustabor.uz/ru/blog/postuplenie-v-vuzy-uzbekistana-20262027-polnoe-rukovodstvo-dlya-abiturientov).
- **Национальный сертификат вместо теста по предмету.**
  - Таблица «уровень → балл» (A+/A — 93 и 63, B+ — 85,9 и 58,2, … C — 65,8
    и 44,6) — по [testmakon.uz](https://testmakon.uz/news/article/milliy-sertifikat-2027-yoriqnoma/).
  - **Ориентир по нижней границе уровня.** На странице так и подписано.
    Перед запуском сверить с UZBMB.
- **Проходные баллы** в макет не выводим: они зависят от вуза, года и формы
  обучения. Вместо них — баллы самих преподавателей с их сайта.
- **Даты экзаменов 2027 года** не объявлены, отсчёт до экзамена не делали.

Отклонили:
- Lenis — это scroll-jacking;
- GSAP — не MIT, а `motion` уже есть;
- React Bits — MIT + Commons Clause;
- Aceternity — закрытая лицензия;
- Remix Icon — с 2026 года своя лицензия;
- пресет ui-ux-pro-max: Claymorphism, Baloo и Comic Neue — детский, а
  аудитория 16–18 лет.
