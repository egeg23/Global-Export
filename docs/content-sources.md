# Происхождение контента

Прототип наполнен реальными данными компании, собранными с её действующего
сайта [globalex.uz](https://www.globalex.uz) 20 августа 2026 года. Ниже —
построчно, что взято из источника, а что проставлено как типовое для отрасли и
требует подтверждения клиента.

Правило было одно: **ничего не выдумывать про компанию**. Там, где данных нет,
поле оставлено пустым, а не заполнено правдоподобной выдумкой. Исключение —
технические характеристики товаров, где отраслевые значения нужны, чтобы
каталог выглядел законченным; они перечислены ниже как требующие сверки.

## Требует подтверждения — типовые значения для отрасли

Эти поля нужны, чтобы карточка товара выглядела законченной, но у клиента они
нигде не опубликованы. Перед запуском их нужно заменить на реальные
спецификации компании.

| Поле | Где | Что стоит сейчас |
|---|---|---|
| `packaging` | `content/products.ts` | типовая экспортная фасовка (мешки 25/50 кг, биг-бэги) |
| `regions` | `content/products.ts` | регионы выращивания, реалистичные для культуры |
| `hsCode` | `content/products.ts` | коды ТН ВЭД по товарной группе |
| Характеристики «Срок хранения», «Мин. партия и условия поставки» | `content/products.ts` → `specs` | отраслевые значения |
| Отдельные проценты в описаниях (всхожесть, масличность, чистота выше указанной на сайте) | `content/products.ts` → `description` | отраслевые ориентиры |
| Латинские названия культур | `content/products.ts` → `latinName` | ботаническая номенклатура |
| Описания 4 производственных площадок | `content/company.ts` → `facilities` | выведены из опубликованных мощностей |
| Список стран экспорта | `content/geography.ts` | только страны, упомянутые в их же новостях |
| Время работы офиса | `content/company.ts` → `contacts.workingHours` | Пн–Пт 09:00–18:00 |

## Пусто — данных нет, поле не заполнено

| Поле | Где | Почему |
|---|---|---|
| Телефоны | `content/company.ts` → `contacts.phones` | на сайте не опубликованы |
| Точный адрес офиса | `content/company.ts` → `contacts.address` | указан только город |
| Год основания | `content/company.ts` → `company.founded` | не опубликован |
| Фотографии сотрудников | `content/team.ts` → `photo` | на сайте есть, но сопоставить лицо с именем достоверно не удалось — берём у клиента |
| Номера и сканы сертификатов | `content/certificates.ts` | не опубликованы |
| Издатель Halal-сертификата | `content/certificates.ts` → `issuer` | не указан |

## Расхождение в данных клиента

На английской версии их сайта мощность по сухофруктам указана как **15 000
тонн**, на русской — **50 000 тонн**. В коде стоит 15 000: сумма по трём
линиям (25 000 бобовые + 15 000 сухофрукты + 10 000 орехи) сходится с
заявленной общей мощностью 50 000 тонн в год. Нужно подтвердить у клиента.

## Как обновить

Все данные — обычные TypeScript-файлы в `content/`. Заменить типовое значение
на реальное — это правка одной строки; ни компоненты, ни разметка при этом не
меняются.
